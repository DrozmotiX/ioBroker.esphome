## Do I have to install Python or pip myself?

<!-- abschnitt: prio=B; gewicht=2; readme=covered; cluster=dashboard-09; features=dashboard-enable,requirements-internet -->
<!-- muss beantworten: Der Adapter bringt seine eigene Python-Umgebung mit; du brauchst nur Node.js 22.12 oder neuer und beim ersten Dashboard-Start Internetzugang. -->

No. The adapter needs no Python for the devices. Only the integrated dashboard needs Python, and the adapter creates its own environment for it and installs ESPHome there. It does not use a Python or pip on your system.
<!-- quelle: code=src/main.ts:358-404@v2.0.0-beta.2; code=src/lib/dashboard.ts:540-591@v2.0.0-beta.2; forum=1243713; issue=#259 -->

You only need Node.js 22.12 or newer. On the first start of the dashboard the adapter downloads Python and the packages from the internet, which takes a few minutes. The Python version is set under "Advanced" in the field "Python version", the default is 3.13.2.
<!-- quelle: code=package.json:29-31@v2.0.0-beta.2; code=src/lib/dashboard.ts:572-583@v2.0.0-beta.2; code=admin/jsonConfig.json5:565-580@v2.0.0-beta.2 -->

## Which systems and hardware does the adapter run on?

<!-- abschnitt: prio=A; gewicht=13; readme=missing; cluster=dashboard-08,logs-install-14,logs-install-17,logs-install-19; features=dashboard-enable,requirements-runtime -->
<!-- muss beantworten: Welche Plattformen das integrierte Dashboard unterstützt (64-Bit-Linux, macOS), Docker als Alternative, Hardwarebedarf, wann ein externes Dashboard besser ist. -->

The adapter runs on any system with ioBroker and Node.js 22.12 or newer. The integrated ESPHome Dashboard runs only on 64-bit Linux and macOS.
<!-- quelle: code=package.json:29-31@v2.0.0-beta.2; interview=3 -->

| What | Requirement |
|---|---|
| Adapter with devices | Node.js 22.12 or newer, admin 7.8.20 or newer, js-controller 6.0.11 or newer |
| Integrated dashboard | additionally 64-bit Linux or macOS and internet access at startup |
| Dashboard with "Use Docker Integration (Beta)" | additionally Docker on the ioBroker host |
<!-- quelle: code=package.json:29-31@v2.0.0-beta.2; code=io-package.json:171-180@v2.0.0-beta.2; code=admin/jsonConfig.json5:381-392@v2.0.0-beta.2; interview=3 -->

The adapter needs no Python for the devices, it talks to them directly through the Native API. Only the integrated dashboard needs Python. The adapter creates its own environment for it at startup, with Python 3.13.2 by default.
<!-- quelle: code=src/lib/dashboard.ts:159@v2.0.0-beta.2; code=src/lib/dashboard.ts:540-583@v2.0.0-beta.2; interview=1 -->

A Raspberry Pi with a 64-bit processor is still a 32-bit system if the operating system is installed in 32 bit. There the dashboard only starts after reinstalling with a 64-bit operating system.
<!-- quelle: forum=983298; issue=#138 -->

### What hardware do I need?

Any hardware that runs ioBroker is enough for the devices. The dashboard compiles firmware, which needs a lot of CPU and memory. A Raspberry Pi 3 becomes very slow, a Raspberry Pi 4 runs stable. If your host is too weak or runs Windows, run the dashboard on another computer.
