# ESPHome – Documentation

The ESPHome adapter connects devices with ESPHome firmware to ioBroker through the Native API: read sensors, control lights, switches and more, optionally with an integrated ESPHome Dashboard.

The documentation is built around the questions users asked in the forum and in the issues. Every heading is such a question.

- **[Getting started](01.erste-schritte/README.md):** Installing ESPHome and connecting the first device.
- **[Guides](02.anleitungen/README.md):** Guides by task: connecting devices, using the dashboard, controlling devices, working with scripts and VIS.
- **[Reference](03.referenz/README.md):** All settings, created states, commands and log messages to look up.
- **[Troubleshooting](04.fehlerbehebung/README.md):** The most common error messages and connection problems and what helps.
- **[Background](05.hintergrund/README.md):** How the adapter talks to the devices, briefly explained.
