## Why are all devices offline or reporting "incorrect password" after a restart or update?

<!-- abschnitt: prio=B; gewicht=6; readme=missing; cluster=connection-setup-07; features=device-startup-reconnect,device-credentials-storage,info-device-online -->
<!-- muss beantworten: Status API password incorrect, Zugangsdaten im Reiter Geräte über Verbindungseinstellungen ändern prüfen. -->

At startup the adapter sets `info._online` of all devices to `false`. It then reads address and credentials from the device objects and reconnects to every device. It does not need discovery for this. Until every device has answered, some are still offline.
<!-- quelle: code=src/main.ts:163-169@v2.0.0-beta.2; code=src/main.ts:248-285@v2.0.0-beta.2; code=src/main.ts:2011-2039@v2.0.0-beta.2; forum=608918; issue=#179 -->

If a device stays offline, check the tab "Devices" or `info._connectionStatus`:

| Status | Cause | Fix |
|---|---|---|
| `API password incorrect` | The device no longer accepts the password, e.g. since ESPHome 2026.1 | "Change connection settings", enter the key |
| `Encryption Key Missing` | The device now uses a key | same |
| `unreachable` | Device off or at another address | Check device and address |
<!-- quelle: code=src/main.ts:860-886@v2.0.0-beta.2; code=src/lib/deviceManagement.ts:405-432@v2.0.0-beta.2; issue=#66; issue=#189 -->

If the address has changed, delete the device in the tab "Devices" and add it at the new address. A fixed address in the router prevents this.
<!-- quelle: code=src/lib/deviceManagement.ts:117-118@v2.0.0-beta.2; forum=648291 -->

**See also:** [API password and ESPHome 2026.1](../01.erste-schritte/03.erstes-geraet.md#api-password-still-work-esphome)
