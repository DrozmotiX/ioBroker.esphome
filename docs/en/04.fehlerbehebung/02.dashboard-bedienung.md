# What to do when the dashboard runs but misbehaves?

<!-- seite: gewicht=5; de=de/04.fehlerbehebung/02.dashboard-bedienung.md -->

<a id="ota-update-abort-time-out"></a>

## Why does the OTA update abort or time out?

<!-- abschnitt: prio=B; gewicht=2; readme=missing; cluster=dashboard-22; features=dashboard-enable -->
<!-- muss beantworten: OTA läuft zwischen Dashboard und Gerät; Timeout direkt nach dem Upload ist normal; Netzwerk und Gerät prüfen. -->

The OTA update runs between dashboard and device, the adapter is not involved.
<!-- quelle: code=src/lib/dashboard.ts:613-617@v2.0.0-beta.2; forum=814434 -->

A timeout right after a complete upload is normal. The device restarts with the new firmware and is briefly unreachable, then the adapter connects again.
<!-- quelle: forum=688695; code=src/main.ts:854-918@v2.0.0-beta.2 -->

If the upload stops in the middle, it is almost always the network or the device:

1. Check the Wi-Fi signal of the device. Below about -80 dBm uploads often fail.
2. Check whether a firewall between the ioBroker host and the device blocks the OTA port.
3. If that does not help, flash once by cable.
<!-- quelle: extern=esphome.io/components/ota -->

**See also:** [Flash by cable](../01.erste-schritte/04.dashboard-einschalten.md#flash-device-first-time-if)

## Why is the dashboard UI broken in the browser?

<!-- abschnitt: prio=B; gewicht=3; readme=missing; cluster=dashboard-23,dashboard-26; features=dashboard-url-admin-tab,dashboard-enable -->
<!-- muss beantworten: Der Tab zeigt das Dashboard nur eingebettet; Dashboard direkt im Browser öffnen, Browser-Cache leeren, anderen Browser testen. -->

The tab "ESPHome" only embeds the dashboard, the interface itself comes from ESPHome. Display errors in the editor or the log window are therefore usually caused by the dashboard or the browser.
<!-- quelle: code=admin/jsonTab.json5:77-83@v2.0.0-beta.2; forum=990451; forum=686608 -->

1. Open the dashboard directly in a browser tab of its own at `http://<ioBroker IP>:6052`.
2. Clear the browser cache or reload the page with Ctrl+F5.
3. Try another browser.
<!-- quelle: code=io-package.json:199@v2.0.0-beta.2; forum=990451 -->

If the error also shows directly in the browser, it is in the dashboard. Another ESPHome version may help then.

**See also:** [Choose the dashboard version](../02.anleitungen/03.dashboard-nutzen.md#choose-update-esphome-dashboard-version)
