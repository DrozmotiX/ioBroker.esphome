## What does the warning "esphome has an invalid jsonConfig" mean?

<!-- abschnitt: prio=A; gewicht=9; readme=missing; cluster=logs-install-02; features=admin-tabs-overview -->
<!-- muss beantworten: Harmlos, Feld steht in instancePath, Admin 7.8.20 oder neuer nötig. -->

The warning is harmless, you do not need to do anything. It comes from admin, which checks the description of the settings page, not from the running adapter. Settings are still saved, devices and dashboard work normally.
<!-- quelle: interview=20; issue=#248; forum=1276624; forum=1327822 -->

After `esphome has an invalid jsonConfig:` admin names the field it objects to (`instancePath`). Usually admin just does not know one property of the field, for example the free input next to a list for "ESPHome Dashboard version", the dashboard address or "Python version".
<!-- quelle: issue=#248; forum=1337810; code=admin/jsonConfig.json5:393-418@v2.0.0-beta.2; code=admin/jsonConfig.json5:565-581@v2.0.0-beta.2; interview=20 -->
<!-- issue: A3 -->

The adapter needs admin 7.8.20 or newer. With an older admin the page does not display correctly, so update admin first. If the dashboard does not start at the same time, this warning is not the cause: [Dashboard does not start](01.dashboard-startet-nicht.md#dashboard-not-start-pillow-esphome).
<!-- quelle: code=io-package.json:176-180@v2.0.0-beta.2; forum=1337810; interview=20 -->

**See also:** [Save buttons active or layout unusable](#save-buttons-active-layout-unusable) · [Instance stays red after install or update](../01.erste-schritte/02.installation.md#instance-stay-red-after-install)

## Why are save buttons active or the layout unusable on mobile?

<!-- abschnitt: prio=B; gewicht=4; readme=missing; cluster=logs-install-05; features=admin-tabs-overview,device-ip-dropdown,device-load-table -->
<!-- muss beantworten: Admin 7.8.20 oder neuer nutzen; Geräte stehen im Reiter Geräte (Gerätemanager); Seite neu laden. -->

The settings page needs admin 7.8.20 or newer. With older versions parts are missing, e.g. the device management in the tab "Devices". Update the admin adapter and reload the page.
<!-- quelle: code=io-package.json:171-180@v2.0.0-beta.2; code=admin/jsonConfig.json5:255-280@v2.0.0-beta.2; forum=1347072 -->

The devices are shown as cards in the tab "Devices", where you add, change and delete them without "Save". You only need "Save" for the other tabs.
<!-- quelle: code=src/lib/deviceManagement.ts:160-176@v2.0.0-beta.2; code=src/lib/deviceManagement.ts:378-456@v2.0.0-beta.2; forum=1221826; issue=#139 -->
