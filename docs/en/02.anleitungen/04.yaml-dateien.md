## How do I upload, view or delete YAML files?

<!-- abschnitt: prio=B; gewicht=2; readme=covered; cluster=dashboard-24; features=yaml-upload,yaml-list,yaml-download,yaml-delete,yaml-directory -->
<!-- muss beantworten: Reiter YAML-Dateien: Datei aus der Liste wählen, In Editor öffnen, ändern und hochladen; Hochladen überschreibt, Löschen mit Rückfrage und endgültig; Instanz muss laufen. -->

You do this in the tab "YAML Files" of the instance settings. The instance must be running. The files are in the folder `iobroker-data/esphome.<instance>`, where the dashboard reads them as well.
<!-- quelle: code=admin/jsonConfig.json5:602-640@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:90-100@v2.0.0-beta.2; issue=#122 -->

| Task | How |
|---|---|
| view | Choose the file under "YAML file", "Open in Editor". The content then appears below in "YAML Content". |
| change | Open the file, edit "YAML Content", "Upload File". |
| create | Fill in "Filename (e.g., my-device.yaml)" and "YAML Content", "Upload File". |
| delete | Choose the file under "YAML file", "Delete File", confirm. |
| reload the list | "Refresh File List" |
<!-- quelle: code=admin/jsonConfig.json5:649-812@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:363-399@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:451-489@v2.0.0-beta.2 -->

The file name must end in `.yaml` or `.yml` and must not contain a folder. "Upload File" overwrites a file with the same name without asking, "Delete File" deletes for good.
<!-- quelle: code=src/lib/yamlFileManager.ts:280-296@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:383-384@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:474@v2.0.0-beta.2; issue=#246 -->

<a id="fonts-images-include-files-local"></a>

## Where do fonts, images, include files and local external_components go?

<!-- abschnitt: prio=B; gewicht=4; readme=partial; cluster=dashboard-03; features=yaml-directory,yaml-upload -->
<!-- muss beantworten: Der Upload nimmt nur YAML; andere Dateien kopierst du ins esphome-Datenverzeichnis der Instanz. -->

The tab "YAML Files" only accepts YAML files. Copy fonts, images, include files and local `external_components` yourself into the folder `iobroker-data/esphome.<instance>` on the ioBroker host, subfolders are fine.
<!-- quelle: code=src/lib/yamlFileManager.ts:280-296@v2.0.0-beta.2; code=src/lib/yamlFileManager.ts:90-100@v2.0.0-beta.2; forum=868414; issue=#144; issue=#219 -->

In the YAML, give paths relative to this folder, e.g. `fonts/arial.ttf`. The files must belong to the user ioBroker runs as. If you copied them as another user, `iobroker fix` corrects the permissions.
<!-- quelle: extern=esphome.io/components/font; forum=994032 -->

```yaml
font:
  - file: "fonts/arial.ttf"
    id: font_main
    size: 20
```
<!-- quelle: extern=esphome.io/components/font -->

With "Use Docker Integration (Beta)" the folder is in the same place, the container sees it as well.
<!-- quelle: code=README.md:240-241@v2.0.0-beta.2; code=src/lib/dashboard.ts:752-753@v2.0.0-beta.2 -->

## What goes into secrets.yaml and what happens without it?

<!-- abschnitt: prio=B; gewicht=3; readme=missing; cluster=dashboard-20; features=yaml-directory,yaml-upload -->
<!-- muss beantworten: secrets.yaml wird nicht automatisch angelegt, ohne sie scheitert das Dashboard; Upload der Datei ist möglich. -->

`secrets.yaml` holds values that should not be in every device YAML, e.g. Wi-Fi credentials and API keys. It is in the folder `iobroker-data/esphome.<instance>` next to the device YAMLs. In a device YAML you fetch a value with `!secret <name>`.
<!-- quelle: extern=esphome.io/guides/faq; forum=1254262 -->

```yaml
# secrets.yaml
wifi_ssid: "MyWiFi"
wifi_password: "<Wi-Fi password>"
```
<!-- quelle: extern=esphome.io/guides/faq -->

The adapter does not create the file. If it is missing, every YAML that uses `!secret` fails and the dashboard reports an error. Create it in the dashboard via "Secrets" or upload it as `secrets.yaml` in the tab "YAML Files".
<!-- quelle: code=src/lib/yamlFileManager.ts:363-399@v2.0.0-beta.2; forum=1264472; forum=1058150 -->

<a id="devices-back-into-dashboard-after"></a>

## How do I get my devices back into the dashboard after a reinstall or move?

<!-- abschnitt: prio=B; gewicht=5; readme=partial; cluster=dashboard-17; features=yaml-directory,yaml-upload,yaml-list -->
<!-- muss beantworten: YAML-Dateien liegen im Datenverzeichnis der Instanz; zurückkopieren oder hochladen, Pfad beachten. -->

The dashboard shows exactly the YAML files in the folder `iobroker-data/esphome.<instance>`. If it is empty after a reinstall or a move, the files are missing there.
<!-- quelle: code=src/lib/yamlFileManager.ts:90-100@v2.0.0-beta.2; code=src/lib/dashboard.ts:613-617@v2.0.0-beta.2; forum=1275541; forum=1027194 -->

1. Copy the YAML files and `secrets.yaml` from the backup or the old host into this folder. You can also upload single files in the tab "YAML Files".
2. If the files belong to a user other than ioBroker afterwards, run `iobroker fix`.
3. Reload the dashboard in the browser.
<!-- quelle: code=src/lib/yamlFileManager.ts:363-399@v2.0.0-beta.2; forum=691261; forum=733079 -->

If you have no YAML left but the device still runs, the dashboard may show it with "Adopt". This creates a new YAML that you complete.
<!-- quelle: code=README.md:117-131@v2.0.0-beta.2 -->
