# How do I let devices be discovered automatically and control which ones are listed?

## Why does auto-discovery report routers or foreign devices and how do I exclude an IP?

<!-- abschnitt: prio=B; gewicht=7; readme=missing; cluster=connection-setup-13; features=discovery-mdns,ignore-list,autodiscovery-setting,discovery-new-device-list -->
<!-- muss beantworten: Ignorierliste im Bereich Erkennung der Haupteinstellungen (exakter Abgleich), wirkt nur auf die Erkennung; gefundene Geräte im Reiter Geräte über Gefundenes Gerät hinzufügen übernehmen. -->

Discovery reports everything on the network that answers the search for ESPHome devices. Some routers and other devices answer as well and then appear in the tab "Devices" in the group "Discovered, not added yet". The adapter never connects to discovered devices on its own, they stay there until you add them.
<!-- quelle: code=src/main.ts:316-346@v2.0.0-beta.2; code=src/lib/deviceManagement.ts:338-369@v2.0.0-beta.2; forum=589502; issue=#130; issue=#175 -->

This excludes an address:

1. Open the instance settings, tab "Main settings", section "Discovery".
2. Enter the address in the table "IP addresses to be excluded by device discovery". Name and description are just for you.
3. Save. The instance restarts and skips the address from now on.
<!-- quelle: code=admin/jsonConfig.json5:131-180@v2.0.0-beta.2; code=src/main.ts:291-304@v2.0.0-beta.2 -->

The address must be written exactly as the device reports it. The list only affects discovery, a device you already added keeps connecting. If you do not need discovery at all, switch off "Device discovery enabled" and add devices by hand.
<!-- quelle: code=src/main.ts:318-323@v2.0.0-beta.2; code=src/main.ts:174-187@v2.0.0-beta.2; code=admin/jsonConfig.json5:104-113@v2.0.0-beta.2 -->

<a id="choose-network-interface-device-discovery"></a>

## Can I choose the network interface for device discovery?

<!-- abschnitt: prio=B; gewicht=1; readme=missing; cluster=connection-setup-14; features=discovery-listening-address,autodiscovery-setting,discovery-mdns -->
<!-- muss beantworten: Die Empfangsadresse der Erkennung (leer oder 0.0.0.0 = alle IPv4-Schnittstellen, eine IPv6-Adresse des Rechners = IPv6 auf dieser Schnittstelle) gilt nur für die Erkennung, nicht für die Verbindungen zu den Geräten. -->

Yes. In the tab "Main settings", section "Discovery", "Listening address" sets the interface the adapter searches on. The field appears when "Device discovery enabled" is on.
<!-- quelle: code=admin/jsonConfig.json5:116-128@v2.0.0-beta.2; code=src/main.ts:306-314@v2.0.0-beta.2; issue=#67 -->

| Entry | Effect |
|---|---|
| empty or `0.0.0.0` | searches on all IPv4 interfaces (default) |
| IPv4 address of the ioBroker host | searches on this interface only |
| IPv6 address of the ioBroker host | searches over IPv6 on this interface |
<!-- quelle: code=src/lib/discoveryOptions.ts:1-44@v2.0.0-beta.2; code=io-package.json:195@v2.0.0-beta.2 -->

If the address belongs to no interface, the log shows a warning and the adapter searches on all IPv4 interfaces. The setting only applies to discovery. The adapter always connects to added devices by their address.
<!-- quelle: code=src/main.ts:307-313@v2.0.0-beta.2; code=src/main.ts:358-404@v2.0.0-beta.2 -->

## How do I find devices in another VLAN or when ioBroker runs in Docker?

<!-- abschnitt: prio=B; gewicht=5; readme=missing; cluster=connection-setup-15; features=discovery-mdns,requirements-esphome-api,device-add-update-sendto,discovery-listening-address -->
<!-- muss beantworten: mDNS bleibt im Subnetz; Geräte per IP-Adresse oder Hostname manuell hinzufügen, Firewall TCP 6053 zum Gerät, Docker mit Host-Netzwerk für die Erkennung. -->

Discovery uses mDNS, and mDNS only reaches the local network. It therefore does not find devices in another VLAN or behind a Docker network. Add such devices by hand with their IP address or host name, the connection itself works across networks.
<!-- quelle: code=src/main.ts:289-346@v2.0.0-beta.2; code=src/lib/deviceManagement.ts:378-396@v2.0.0-beta.2; forum=1328505; forum=1006129; issue=#72 -->

For this the ioBroker host must reach the device on TCP port 6053, the port of the ESPHome API. Allow it in the firewall between the networks.
<!-- quelle: code=src/main.ts:368-388@v2.0.0-beta.2; extern=esphome.io/components/api; forum=689276 -->

If ioBroker runs in Docker, the container only sees mDNS with the host network. Without the host network, add the devices by hand.
<!-- quelle: forum=733227; code=README.md:235-237@v2.0.0-beta.2 -->

## Does the adapter support ioBroker.discovery?

<!-- abschnitt: prio=B; gewicht=1; readme=missing; cluster=connection-setup-21; features=autodiscovery-setting -->
<!-- muss beantworten: Klärt, dass der Adapter eine eigene mDNS-Erkennung hat und was ioBroker.discovery damit zu tun hat; offen bis zur Bestätigung. -->

The adapter has its own discovery and does not need the adapter ioBroker.discovery. It runs while "Device discovery enabled" is on and shows discovered devices in the tab "Devices".
