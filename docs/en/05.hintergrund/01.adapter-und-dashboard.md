# How do the adapter and the ESPHome dashboard relate?

## Can I use ESPHome without Home Assistant and run the dashboard in the adapter?

<!-- abschnitt: prio=B; gewicht=3; readme=covered; cluster=dashboard-13; features=dashboard-enable,requirements-esphome-api -->
<!-- muss beantworten: Der Adapter startet ein eigenes Dashboard, beide Teile sind lose gekoppelt. -->

Yes. ESPHome does not need Home Assistant. The adapter controls the devices over the Native API and can bring the ESPHome Dashboard along, where you write, compile and flash YAML files.
<!-- quelle: code=src/main.ts:358-404@v2.0.0-beta.2; code=README.md:83-91@v2.0.0-beta.2; forum=661691; forum=757336; issue=#47 -->

You switch the dashboard on in the tab "ESPHome Dashboard" with "Enable ESPHome Dashboard", it is off by default. Adapter and dashboard work separately: a device in the dashboard is not automatically in the adapter, and vice versa.
<!-- quelle: code=admin/jsonConfig.json5:369-378@v2.0.0-beta.2; code=io-package.json:197@v2.0.0-beta.2; code=README.md:102-131@v2.0.0-beta.2 -->

## Why do adapter and dashboard show the device status differently?

<!-- abschnitt: prio=B; gewicht=9; readme=partial; cluster=dashboard-16,connection-setup-10; features=dashboard-enable,device-add-update-sendto,info-device-online,discovery-mdns,requirements-esphome-api -->
<!-- muss beantworten: Dashboard und Adapter prüfen den Status getrennt; erklärt, warum die Anzeigen abweichen können, und was Docker oder VLAN daran ändern. -->

Adapter and dashboard check the device status independently. The adapter shows whether its API connection to the device stands (`info._online`). The dashboard checks on its own whether it finds the device on the network, and needs mDNS for that.
<!-- quelle: code=src/main.ts:2134-2180@v2.0.0-beta.2; code=README.md:102-131@v2.0.0-beta.2; forum=1133805; issue=#157; issue=#208 -->

So a device can be online in the adapter and offline in the dashboard, especially when:

- the device is in another network or VLAN than the ioBroker host,
- ioBroker runs in Docker without the host network,
- the router does not resolve mDNS names.
<!-- quelle: code=README.md:235-236@v2.0.0-beta.2; forum=1169212; forum=1265041 -->

For control from ioBroker only the status in the adapter counts. A device that is only in the adapter gets into the dashboard via "Adopt" or a new YAML.
<!-- quelle: code=README.md:117-131@v2.0.0-beta.2 -->
