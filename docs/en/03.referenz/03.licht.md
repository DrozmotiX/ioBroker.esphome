## Which datapoints does an RGB/RGBW lamp have and which values does it expect?

<!-- abschnitt: prio=A; gewicht=15; readme=partial; cluster=entities-scripts-05,entities-scripts-06; features=entity-light,light-color-hex -->
<!-- muss beantworten: Helligkeit und Farben 0 bis 255, Hex-Farbe, Farbtemperatur, welche Werte der Lichtbefehl enthält. -->

A light has one state each under `esphome.0.<device>.Light.<key>` for on/off, brightness, color channels, color temperature, effect and hex color. Write brightness and color channels as a number from 0 to 255, the hex color as `#rrggbb`.
<!-- quelle: code=src/main.ts:1058-1070@v2.0.0-beta.2; code=src/main.ts:1160-1176@v2.0.0-beta.2; code=src/main.ts:1857-1872@v2.0.0-beta.2 -->

### The states

Only the values the light reports exist. A plain on/off light therefore has fewer states than an RGBW light.
<!-- quelle: code=src/main.ts:994-1150@v2.0.0-beta.2 -->

| State | Values | Meaning |
|---|---|---|
| `state` | `true` / `false` | on or off |
| `brightness` | 0 to 255 | overall brightness |
| `red`, `green`, `blue` | 0 to 255 each | color channels |
| `white` | 0 to 255 | white channel, RGBW only |
| `colorBrightness` | 0 to 255 | brightness of the color part |
| `coldWhite`, `warmWhite` | 0 to 255 each | cold and warm white |
| `colorHEX` | e.g. `#ff6600` or `#f60` | color as hex value, only for lights with red, green and blue |
| `colorTemperature` | number | color temperature on the same 0 to 255 scale as brightness, not in Kelvin or mired |
| `colorMode` | number | ESPHome color mode, e.g. `35` for RGB |
| `effect` | text | name of the light effect from the YAML |
| `transitionLength` | milliseconds | transition time, sent with every command |
| `config.rgbAutoWhite` | `true` / `false` | RGBW only: `#ffffff` switches to the white channel |
<!-- quelle: code=src/main.ts:1058-1145@v2.0.0-beta.2; code=src/main.ts:1160-1176@v2.0.0-beta.2; code=src/main.ts:1704-1718@v2.0.0-beta.2; code=src/main.ts:1930-1944@v2.0.0-beta.2; interview=18 -->

An invalid hex value is dropped without a message, the light stays as it is.
<!-- quelle: code=src/main.ts:1878-1883@v2.0.0-beta.2 -->

### How to switch a light

1. In admin, open the "Objects" tab and go to `esphome.0.<device>.Light.<key>`.
2. Write a state, e.g. `brightness` to `128` or `colorHEX` to `#ff6600`.
3. The adapter sends a complete light command. When the light reports its new state, the value is confirmed (`ack = true`).
<!-- quelle: code=src/main.ts:1857-1983@v2.0.0-beta.2 -->

```javascript
setState('esphome.0.<device>.Light.<key>.state', true);
setState('esphome.0.<device>.Light.<key>.colorHEX', '#ff6600');
```
<!-- quelle: code=src/main.ts:1878-1886@v2.0.0-beta.2 -->

The command always contains on/off, transition time and the last known values, but only those the light supports according to its color modes. An effect is only sent when `effect` is not empty.
<!-- quelle: code=src/main.ts:1902-1978@v2.0.0-beta.2 -->
