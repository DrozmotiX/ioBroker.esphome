## Kann ich ESPHome ohne Home Assistant nutzen und das Dashboard im Adapter betreiben?

<!-- abschnitt: prio=B; gewicht=3; readme=covered; cluster=dashboard-13; features=dashboard-enable,requirements-esphome-api -->
<!-- muss beantworten: Der Adapter startet ein eigenes Dashboard, beide Teile sind lose gekoppelt. -->

Ja. ESPHome braucht kein Home Assistant. Der Adapter steuert die Geräte über die Native API und kann auf Wunsch das ESPHome-Dashboard mitbringen, in dem du YAML-Dateien schreibst, kompilierst und flashst.
<!-- quelle: code=src/main.ts:358-404@v2.0.0-beta.2; code=README.md:83-91@v2.0.0-beta.2; forum=661691; forum=757336; issue=#47 -->

Das Dashboard schaltest du im Reiter „ESPHome-Dashboard“ mit „ESPHome-Dashboard aktivieren“ ein, standardmäßig ist es aus. Adapter und Dashboard arbeiten getrennt: Ein Gerät im Dashboard ist nicht automatisch im Adapter, und umgekehrt.
