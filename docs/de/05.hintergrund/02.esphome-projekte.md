## Funktionieren eigene Komponenten und bestehende ESPHome-Projekte mit dem Adapter?

<!-- abschnitt: prio=B; gewicht=4; readme=partial; cluster=entities-scripts-27; features=entity-sensor,entity-textsensor,requirements-esphome-api -->
<!-- muss beantworten: Alles, was die native API als bekannte Entität liefert, erscheint; fremde Typen werden nur gewarnt. -->

Ja, solange die Firmware ihre Werte als Entitäten über die API meldet. Woher eine Entität kommt, ob aus ESPHome, einer externen Komponente oder einem fertigen Projekt, ist dem Adapter egal.
<!-- quelle: code=src/main.ts:569-627@v2.0.0-beta.2; forum=818941; forum=817053 -->

Der Adapter kennt diese Typen: Sensor, Binärsensor, Textsensor, Switch, Number, Text, Select, Button, Lock, Cover, Fan, Light und Climate. Meldet ein Gerät einen anderen Typ, steht einmal `DeviceType <Typ> not yet supported` mit den Details im Log, und für diesen Typ entstehen keine Werte.
<!-- quelle: code=src/main.ts:715-813@v2.0.0-beta.2; code=src/main.ts:1996-2009@v2.0.0-beta.2 -->

Liefert eine Komponente einen JSON-Text, kommt er als ein Text-Datenpunkt an. Den zerlegst du im Skript mit `JSON.parse`. Vorhandene YAML-Dateien kannst du meist unverändert im Dashboard des Adapters nutzen.
<!-- quelle: code=src/main.ts:952-985@v2.0.0-beta.2; forum=1042377; forum=1315772 -->
