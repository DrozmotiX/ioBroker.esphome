## Wie wähle oder aktualisiere ich die ESPHome-Dashboard-Version, auch ältere?

<!-- abschnitt: prio=A; gewicht=12; readme=missing; cluster=dashboard-05,logs-install-09; features=dashboard-version-select,dashboard-info-states,requirements-internet,dashboard-pillow-version,migration-pinned-versions,dashboard-clear-autopy-cache -->
<!-- muss beantworten: Dropdown ESPHome-Version und Pillow-Version, nur erste GitHub-Seite wird gelistet, Neustart nach Änderung; neuere Version über Dropdown. -->

**Kurz:** Du wählst die Version in den Instanz-Einstellungen unter „ESPHome Dashboard-Version“ und passend dazu die „Pillow-Version“. Nach dem Speichern startet die Instanz neu und installiert genau diese Versionen. Ein Update des Adapters brauchst du dafür nicht.
<!-- quelle: code=admin/jsonConfig.json5:618-639@v1.0.1; code=main.js:342-420@v1.0.1; issue=#118 -->

Voreingestellt sind ESPHome `2026.6.5` und Pillow `12.2.0`. Diese Kombination lässt sich zuverlässig installieren. Neuere ESPHome-Versionen ab 2026.7 scheiterten bei vielen Nutzern beim Installieren.
<!-- quelle: code=main.js:26-31@v1.0.1; code=io-package.json:185-186@v1.0.1; issue=#463; issue=#479 -->

### So gehst du vor

1. Öffne die Instanz-Einstellungen von ESPHome, Reiter „ESPHome-Dashboard“.
2. Wähle bei „ESPHome Dashboard-Version“ die gewünschte Version aus der Liste.
3. Wähle bei „Pillow-Version“ die Version, die zu dieser ESPHome-Version passt. Welche das ist, siehst du, wenn die Installation scheitert: pip nennt im Log die verlangte Pillow-Version.
4. Speichere. Die Instanz startet neu und richtet die Python-Umgebung mit den neuen Versionen ein. Das dauert einige Minuten.
5. Im Log steht danach „Starting ESPHome Dashboard“. Unter `esphome.0._ESPHomeDashboard.selectedVersion` siehst du die verwendete Version, unter `esphome.0._ESPHomeDashboard.newestVersion` die neueste bei GitHub.
<!-- quelle: code=admin/jsonConfig.json5:618-639@v1.0.1; code=main.js:300-364@v1.0.1; code=main.js:396-427@v1.0.1; code=main.js:449@v1.0.1 -->

<!-- bild: screenshot Reiter „ESPHome-Dashboard“ mit geöffneter Liste „ESPHome Dashboard-Version“ -->

### Woher kommt die Liste, und warum fehlen ältere Versionen?

Die ESPHome-Versionen holt der Adapter beim Start von GitHub. Er liest dabei nur die erste Seite der Release-Liste, also etwa die 30 neuesten Releases, Vorabversionen eingeschlossen. Ältere Versionen stehen deshalb meist nicht in der Liste, und eine eigene Eingabe lässt das Feld nicht zu. Die Pillow-Liste kommt von PyPI und enthält die 20 neuesten stabilen Versionen.
<!-- quelle: code=main.js:309-320@v1.0.1; code=main.js:1877-1893@v1.0.1; code=main.js:2176-2200@v1.0.1 -->

Ist GitHub beim Start nicht erreichbar, nimmt der Adapter die Liste vom letzten erfolgreichen Abruf und schreibt eine Warnung ins Log: „Unable to retrieve current Dashboard release versions, using cached values“. Die voreingestellten Versionen `2026.6.5` und `12.2.0` stehen immer zur Auswahl.
<!-- quelle: code=main.js:329-340@v1.0.1; code=main.js:1888-1890@v1.0.1; code=main.js:1923-1925@v1.0.1 -->

### Was bedeutet „Always last available“?

Mit „Always last available“ installiert der Adapter bei jedem Start die neueste Version von GitHub bzw. PyPI. Dein Dashboard wechselt dann ohne dein Zutun auf jedes neue Release, auch auf eines, das sich nicht installieren lässt. Der Adapter warnt deshalb beim Start im Log.
<!-- quelle: code=main.js:349-355@v1.0.1; code=main.js:262-282@v1.0.1; issue=#463 -->

> [!TIP]
> Wähle feste Versionen. Willst du aktualisieren, stell die neue Version gezielt ein und behalte die alte im Kopf, falls du zurück musst.
<!-- quelle: code=main.js:262-282@v1.0.1 -->

Stand deine Instanz vor v1.0.0 auf „Always last available“, hat der Adapter sie beim Update einmalig auf `2026.6.5` und `12.2.0` umgestellt und das im Log vermerkt. Stellst du danach wieder „Always last available“ ein, bleibt das so.
<!-- quelle: code=main.js:199-258@v1.0.1; issue=#463 -->

> [!NOTE]
> Meldet das Dashboard selbst, dass ein Update verfügbar ist, betrifft das nur die Anzeige im Dashboard. Welche Version läuft, bestimmt allein die Einstellung im Adapter.
<!-- quelle: code=main.js:342-357@v1.0.1; code=main.js:398-420@v1.0.1 -->
