## Wie wähle oder aktualisiere ich die ESPHome-Dashboard-Version, auch ältere?

<!-- abschnitt: prio=A; gewicht=12; readme=missing; cluster=dashboard-05,logs-install-09; features=dashboard-version-select,dashboard-info-states,requirements-internet,dashboard-pillow-version,migration-pinned-versions,dashboard-clear-autopy-cache -->
<!-- muss beantworten: Version wählen oder eintippen, Device Builder und Pillow werden passend gewählt, Liste von GitHub, Always last available, Felder unter Fortschrittlich (Pillow, Device Builder, Python). -->

Du wählst die Version in den Instanz-Einstellungen unter „ESPHome Dashboard-Version“ oder tippst sie dort ein. Nach dem Speichern startet die Instanz neu und installiert genau diese Version. Voreingestellt ist `2026.6.5`.
<!-- quelle: code=admin/jsonConfig.json5:394-406@v2.0.0-beta.2; code=io-package.json:187@v2.0.0-beta.2; code=src/lib/dashboard.ts:497-501@v2.0.0-beta.2; issue=#118 -->

Alles, was ESPHome sonst noch braucht, sucht der Adapter passend aus. Ab ESPHome 2026.7.0 installiert er zusätzlich ESPHome Device Builder, das dort das Dashboard bereitstellt. Pillow bringt ESPHome selbst in der passenden Version mit.
<!-- quelle: code=src/lib/dashboardRequirements.ts:66-68@v2.0.0-beta.2; code=src/lib/dashboardRequirements.ts:88-107@v2.0.0-beta.2; issue=#479 -->

### So gehst du vor

1. Öffne die Instanz-Einstellungen, Reiter „ESPHome-Dashboard“.
2. Wähle bei „ESPHome Dashboard-Version“ eine Version aus der Liste. Fehlt sie dort, etwa eine ältere oder eine Beta, tipp sie ein, z. B. `2026.5.3`.
3. Speichere. Die Instanz startet neu und installiert die Version. Das dauert einige Minuten, der ESPHome-Tab zeigt solange das Startprotokoll.
4. Im Log steht danach „Starting ESPHome Dashboard. ESPHome version: …“ mit den installierten Versionen von ESPHome, Pillow und Device Builder.
<!-- quelle: code=admin/jsonConfig.json5:394-406@v2.0.0-beta.2; code=src/lib/dashboard.ts:573-576@v2.0.0-beta.2; code=src/lib/dashboard.ts:619-627@v2.0.0-beta.2; code=admin/jsonTab.json5:36-73@v2.0.0-beta.2 -->

<!-- bild: screenshot Reiter „ESPHome-Dashboard“ mit geöffneter Liste „ESPHome Dashboard-Version“ -->

Die Liste kommt beim Start der Instanz von GitHub und enthält die rund 30 neuesten Releases. Ist GitHub nicht erreichbar, nimmt der Adapter die Liste vom letzten Abruf. `esphome.0._ESPHomeDashboard.selectedVersion` zeigt die verwendete Version, `esphome.0._ESPHomeDashboard.newestVersion` die neueste bei GitHub.
<!-- quelle: code=src/lib/dashboard.ts:458-490@v2.0.0-beta.2; code=src/lib/dashboard.ts:1337-1351@v2.0.0-beta.2 -->

### Was bedeutet „Always last available“?

Damit installiert der Adapter bei jedem Start die neueste ESPHome-Version. Erscheint ein Release, das sich nicht installieren lässt, startet das Dashboard ohne dein Zutun nicht mehr. Wähle deshalb eine feste Version und stell sie zum Aktualisieren gezielt um.
<!-- quelle: code=src/lib/dashboard.ts:405-413@v2.0.0-beta.2; code=src/lib/dashboard.ts:497-506@v2.0.0-beta.2; issue=#463 -->

### Was steht unter „Fortschrittlich“?

| Feld | Standard | Wofür |
|---|---|---|
| „Pillow-Version“ | `Auto Detect` | ESPHome installiert die passende Version selbst. Eine feste Version nur, wenn pip im Log genau diese verlangt. |
| „ESPHome Device Builder-Version“ | `Auto Detect` | neueste Version, die zur gewählten ESPHome-Version passt |
| „Python-Version“ | `3.13.2` | eine Version wie `3.13.2` oder ein Bereich wie `3.12`. Eine Änderung legt die Python-Umgebung beim nächsten Start neu an. |
<!-- quelle: code=admin/jsonConfig.json5:538-581@v2.0.0-beta.2; code=io-package.json:187-190@v2.0.0-beta.2; code=src/lib/dashboardRequirements.ts:77-107@v2.0.0-beta.2 -->

Mit „Docker-Integration verwenden (Beta)“ fallen diese drei Felder weg. Der Adapter startet dann das offizielle ESPHome-Image in der gewählten Version.
<!-- quelle: code=admin/jsonConfig.json5:538-581@v2.0.0-beta.2; code=src/lib/dashboard.ts:752-776@v2.0.0-beta.2 -->

Meldet das Dashboard selbst ein Update, betrifft das nur seine Anzeige. Welche Version läuft, bestimmt allein die Einstellung im Adapter.
<!-- quelle: code=src/lib/dashboard.ts:497-506@v2.0.0-beta.2; code=src/lib/dashboard.ts:580-586@v2.0.0-beta.2 -->

## Wie nutze ich ein externes ESPHome-Dashboard statt des integrierten?

<!-- abschnitt: prio=B; gewicht=4; readme=covered; cluster=dashboard-14; features=dashboard-enable,dashboard-url-admin-tab,requirements-esphome-api -->
<!-- muss beantworten: Integriertes Dashboard abschalten und ESPHome anderswo betreiben; Adapter braucht nur Geräteadresse und Schlüssel; Docker-Integration als Alternative; was der Admin-Tab dann zeigt. -->

Das integrierte Dashboard ist freiwillig. Für die Geräte braucht der Adapter nur deren Adresse und Schlüssel. Wo du die YAML-Dateien bearbeitest und flashst, ist ihm egal.
<!-- quelle: code=README.md:83-91@v2.0.0-beta.2; forum=1349357; forum=607644 -->

1. Lass im Reiter „ESPHome-Dashboard“ „ESPHome-Dashboard aktivieren“ aus.
2. Betreib ESPHome auf einem anderen Rechner, z. B. als Docker-Container oder Home-Assistant-Add-on.
3. Füg die Geräte im Reiter „Geräte“ mit Adresse und Schlüssel hinzu.
4. Soll der Admin-Tab „ESPHome“ das externe Dashboard zeigen, trag im Reiter „ESPHome-Dashboard“ dessen Adresse in „IP-Adresse, unter der ESPHome Dashboard zur Integration in ioBroker Admin ausgeführt wird“ ein und unter „Fortschrittlich“ den Port.
<!-- quelle: code=admin/jsonConfig.json5:369-378@v2.0.0-beta.2; code=README.md:251-255@v2.0.0-beta.2 -->

Derzeit zeigt der Tab mit Admin 8.0.12 oder neuer bei ausgeschaltetem integriertem Dashboard trotzdem nur den Hinweis, dass es nicht aktiviert ist. Bis das behoben ist, öffnest du das externe Dashboard direkt im Browser, z. B. unter `http://<Rechner>:6052`.
<!-- quelle: code=admin/jsonTab.json5:21-26@v2.0.0-beta.2; code=admin/jsonTab.json5:77-83@v2.0.0-beta.2; code=src/lib/dashboard.ts:436-440@v2.0.0-beta.2; code=admin/jsonConfig.json5:407-418@v2.0.0-beta.2; interview=28 -->
<!-- issue: A19 -->

Willst du ESPHome in Docker, aber ohne eigenen Aufwand, nimm „Docker-Integration verwenden (Beta)“. Dann startet der Adapter das offizielle ESPHome-Image selbst. Die Option siehst du nur im Expertenmodus des Admins.
<!-- quelle: code=admin/jsonConfig.json5:381-392@v2.0.0-beta.2; code=README.md:220-246@v2.0.0-beta.2 -->

## Wie zeige ich das Dashboard im Admin-Tab bei HTTPS an?

<!-- abschnitt: prio=B; gewicht=8; readme=covered; cluster=dashboard-12; features=dashboard-url-admin-tab,admin-tab-link -->
<!-- muss beantworten: Mixed Content, Reverse-Proxy und eigene URL im Feld URL des ESPHome-Dashboards; Anmeldung mit Benutzername und Passwort unter Fortschrittlich. -->

Läuft der Admin über HTTPS, blockiert der Browser ein Dashboard, das über HTTP kommt. Du leitest das Dashboard deshalb über den Web- und den Proxy-Adapter, die beide HTTPS können.
<!-- quelle: code=README.md:267-288@v2.0.0-beta.2; issue=#75; issue=#113; forum=745008 -->

1. Richte den Web-Adapter mit HTTPS ein.
2. Installiere den Proxy-Adapter und leg dort einen Pfad an: Kontext `esphome/`, Ziel `http://localhost:6052`.
3. Öffne beim ESPHome-Adapter den Reiter „ESPHome-Dashboard“, Bereich „Fortschrittlich“.
4. Trag in „URL des ESPHome-Dashboards“ die Adresse über den Proxy ein: `https://<ioBroker-IP>:<Web-Port>/proxy.0/esphome/`. Der Web-Port ist meist 8082.
5. Speichere und öffne den Tab „ESPHome“.
<!-- quelle: code=README.md:275-288@v2.0.0-beta.2; code=admin/jsonConfig.json5:582-597@v2.0.0-beta.2 -->

Änderst du danach die IP-Adresse oder den Port des Dashboards, setzt der Adapter das URL-Feld auf `http://<IP>:<Port>` zurück. Trag die Proxy-Adresse dann erneut ein.
<!-- quelle: code=admin/jsonConfig.json5:590-595@v2.0.0-beta.2 -->

Für eine Anmeldung am Dashboard setzt du unter „Fortschrittlich“ „Benutzername des ESPHome-Dashboards“ und „Passwort des ESPHome-Dashboards“, beide oder keins. Sie gelten ab dem nächsten Start des Dashboards.
