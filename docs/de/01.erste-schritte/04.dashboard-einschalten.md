# Wie schalte ich das ESPHome-Dashboard ein und öffne es?

<!-- seite: gewicht=19; en=en/01.erste-schritte/04.dashboard-einschalten.md -->

<a id="dashboard-tab-not-open-localhost"></a>

## Warum öffnet sich der Dashboard-Tab nicht ("localhost verweigert die Verbindung")?

<!-- abschnitt: prio=A; gewicht=13; readme=partial; cluster=dashboard-11; features=dashboard-enable,dashboard-url-admin-tab,admin-tab-link,migration-dashboard-url -->
<!-- muss beantworten: Dashboard-Adresse und Port korrekt eintragen (ohne Port im IP-Feld), nicht localhost für Zugriff von außen, URL-Feld zuletzt bearbeiten, was der Tab beim Start und bei Fehlern zeigt. -->

Trag bei „IP-Adresse, unter der ESPHome Dashboard zur Integration in ioBroker Admin ausgeführt wird“ die Adresse deines ioBroker-Rechners ein, ohne Port. Nimm nicht `localhost` oder `127.0.0.1`.
<!-- quelle: code=admin/jsonConfig.json5:407-418@v2.0.0-beta.2; code=admin/jsonConfig.json5:582-596@v2.0.0-beta.2; forum=1340972; forum=1274190 -->

Der Tab zeigt die Seite unter „URL des ESPHome-Dashboards“. Diese Seite lädt dein Browser, nicht der ioBroker-Rechner. `localhost` zeigt deshalb auf den Rechner, an dem du sitzt, und der Browser meldet „localhost verweigert die Verbindung“.
<!-- quelle: code=admin/jsonTab.json5:84-93@v2.0.0-beta.2; code=io-package.json:165-167@v2.0.0-beta.2; issue=#98 -->

### So gehst du vor

1. Öffne die Instanz-Einstellungen, Reiter „ESPHome-Dashboard“.
2. Setze den Haken bei „ESPHome-Dashboard aktivieren“.
3. Wähle im IP-Feld eine Adresse des ioBroker-Rechners aus der Liste. Die Liste bietet IPv4- und IPv6-Adressen an, ein Hostname geht auch. Schreib keinen Port dazu, den hängt der Adapter selbst an.
4. Unter „Fortschrittlich“ steht der „Port des ESPHome-Dashboards“, Standard `6052`. Darunter füllt sich „URL des ESPHome-Dashboards“ von selbst, z. B. `http://192.168.x.y:6052`. Eine eigene URL trägst du zuletzt ein, weil eine Änderung an IP oder Port sie wieder überschreibt.
5. Speichere. Die Instanz startet neu.
6. Öffne den ESPHome-Tab im Admin-Menü. Während das Dashboard startet, zeigt er einen Hinweis und das Startprotokoll. Sobald das Dashboard antwortet, erscheint es von selbst. Beim ersten Start dauert das einige Minuten.

<!-- bild: screenshot Reiter „ESPHome-Dashboard“ mit Haken, IP-Auswahl und aufgeklapptem Bereich „Fortschrittlich“ mit Port und URL -->

Zeigt der Tab statt des Dashboards einen Text, steht dort der Grund: Instanz läuft nicht, Dashboard nicht aktiviert, keine URL eingetragen oder Start fehlgeschlagen. Im letzten Fall hilft [Warum startet das Dashboard nicht?](../04.fehlerbehebung/01.dashboard-startet-nicht.md#dashboard-not-start-pillow-esphome).

## Wie flashe ich ein Gerät zum ersten Mal, wenn der Server keinen USB-Zugang hat?

<!-- abschnitt: prio=B; gewicht=6; readme=partial; cluster=dashboard-21; features=dashboard-enable -->
<!-- muss beantworten: Erstes Flashen per Browser-Serial am PC oder externem Dashboard, danach OTA über das Adapter-Dashboard. -->

Das erste Flashen braucht eine Kabelverbindung zum Gerät. Hat der ioBroker-Rechner keinen USB-Zugang, z. B. in einer VM oder einem Container, flashst du vom eigenen PC aus. Danach spielst du Änderungen über WLAN (OTA) aus dem Dashboard des Adapters auf.
<!-- quelle: forum=878161; forum=828521; issue=#108 -->

1. Leg das Gerät im Dashboard an und klick bei „Install“ auf „Manual download“.
2. Lade die Firmware herunter.
3. Schließ das Gerät per USB an deinen PC an und flashe die Datei mit einem Flash-Tool, z. B. [ESPHome Web](https://web.esphome.io).
4. Sobald das Gerät im WLAN ist, wählst du bei „Install“ den Weg „Wirelessly“.
<!-- quelle: extern=esphome.io/guides/getting_started_hassio; forum=662120; forum=939862 -->

„Plug into this computer“ im Dashboard funktioniert nur, wenn du das Dashboard über HTTPS öffnest.
