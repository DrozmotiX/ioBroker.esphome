## Auf welchen Systemen und mit welcher Hardware läuft der Adapter?

<!-- abschnitt: prio=A; gewicht=13; readme=missing; cluster=dashboard-08,logs-install-14,logs-install-17,logs-install-19; features=dashboard-enable,requirements-runtime -->
<!-- muss beantworten: Welche Plattformen (64-Bit, armv7, Windows) mit dem integrierten Dashboard laufen, wie viel RAM nötig ist und wann ein externes Dashboard besser ist; offen, bis der Maintainer es bestätigt. -->

**Kurz:** Der Adapter selbst läuft auf jedem System mit ioBroker und Node.js 22 oder neuer. Das integrierte ESPHome-Dashboard wird nur auf **64-Bit-Linux und macOS** unterstützt, nicht auf 32-Bit-Systemen und nicht unter Windows.
<!-- quelle: code=package.json:29-31@v1.0.1; interview=3 -->

Für die Geräte braucht der Adapter kein Python. Er spricht direkt über die Native API mit ihnen. Python braucht nur das integrierte Dashboard: Beim Start legt der Adapter dafür eine eigene Umgebung mit Python 3.13 an und installiert ESPHome hinein. Das klappt nur auf Systemen, für die es passende Python- und ESPHome-Pakete gibt.
<!-- quelle: code=main.js:389-420@v1.0.1; interview=1 -->

| Was | Voraussetzung |
|---|---|
| Adapter mit Geräten | ioBroker, Node.js 22 oder neuer, jedes Betriebssystem |
| Integriertes Dashboard | zusätzlich 64-Bit-Linux oder macOS und beim Start Internetzugang |
| Integriertes Dashboard auf 32-Bit (z. B. Raspberry Pi OS 32 Bit) oder Windows | nicht unterstützt, nutze ein externes Dashboard |
<!-- quelle: code=package.json:29-31@v1.0.1; code=main.js:309-320@v1.0.1; interview=3 -->

> [!IMPORTANT]
> Auch ein Raspberry Pi mit 64-Bit-Kernel kann ein 32-Bit-System sein, wenn das Betriebssystem in 32 Bit installiert ist. Bei Nutzern lief das Dashboard erst nach einer Neuinstallation mit einem 64-Bit-Betriebssystem.
<!-- quelle: forum=983298; issue=#138 -->

### Welche Hardware brauche ich?

Für den Betrieb mit Geräten reicht jede Hardware, auf der ioBroker läuft. Feste Mindestwerte für das Dashboard gibt es nicht. Das Dashboard kompiliert aber Firmware, und das braucht viel Rechenleistung und Arbeitsspeicher. Auf schwacher Hardware wie einem Raspberry Pi 3 kann das den ganzen Rechner ausbremsen, ein Raspberry Pi 4 lief bei Nutzern stabil.
<!-- quelle: forum=1130028; forum=661850; interview=4 -->

> [!TIP]
> Ist dein ioBroker-Rechner schwach, ein 32-Bit-System oder ein Windows-Rechner, lass das integrierte Dashboard aus und betreibe ein externes ESPHome-Dashboard auf einem anderen Rechner. Der Adapter braucht für die Geräte kein Dashboard.
<!-- quelle: interview=3; interview=4 -->
