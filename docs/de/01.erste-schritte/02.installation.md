## Wie installiere ich eine ältere Version oder eine Vorabversion?

<!-- abschnitt: prio=B; gewicht=9; readme=partial; cluster=logs-install-04; features=requirements-runtime -->
<!-- muss beantworten: Schritte für Installation einer bestimmten Version, Vorabversion oder per GitHub-URL inklusive Update-Hinweis. -->

Vorabversionen und ältere Versionen installierst du in der Konsole des ioBroker-Rechners. Das ioBroker-Repository bietet Vorabversionen nicht an.
<!-- quelle: code=README.md:185-210@v2.0.0-beta.2; forum=1278359 -->

| Ziel | Befehl |
|---|---|
| aktuelle Vorabversion | `iobroker url iobroker.esphome@next` |
| bestimmte Version | `iobroker url iobroker.esphome@2.0.0-beta.2` |
| zurück zur freigegebenen Version | `iobroker url iobroker.esphome` |
<!-- quelle: code=README.md:191-206@v2.0.0-beta.2 -->

Alle Versionen mit ihren Änderungen stehen unter [Releases](https://github.com/DrozmotiX/ioBroker.esphome/releases). Die Instanz und ihre Einstellungen bleiben beim Wechsel erhalten. Installierst du den Adapter zum ersten Mal auf diesem Weg, legt ioBroker keine Instanz an. Leg sie dann im Admin im Tab „Adapter“ selbst an.
<!-- quelle: code=README.md:208-209@v2.0.0-beta.2; forum=1272717; issue=#187 -->

## Warum bleibt die Instanz nach Installation oder Update rot?

<!-- abschnitt: prio=B; gewicht=6; readme=missing; cluster=logs-install-07,logs-install-15; features=dashboard-enable,requirements-runtime,dashboard-url-admin-tab -->
<!-- muss beantworten: Instanz ist grün, solange sie läuft (info.connection); rot heißt, sie läuft nicht; Ursache im Log; verbundene Geräte in info.connectedDevices. -->

Die Instanz ist grün, solange der Adapter läuft. Das steht in `esphome.0.info.connection`. Ob Geräte verbunden sind, ändert daran nichts. Die verbundenen Geräte stehen in `esphome.0.info.connectedDevices`.
<!-- quelle: code=src/main.ts:141-146@v2.0.0-beta.2; code=src/main.ts:2182-2193@v2.0.0-beta.2; code=src/lib/connectionState.ts:13-35@v2.0.0-beta.2 -->

Bleibt die Instanz rot, läuft der Adapter nicht. Den Grund findest du im Log der Instanz:

1. Öffne im Admin den Tab „Log“ und filtere auf `esphome.0`.
2. Steht dort ein Hinweis auf die Node.js-Version, installiere Node.js 22.12 oder neuer.
3. Steht dort ein Fehler beim Laden des Adapters, installiere ihn neu, z. B. mit `iobroker url iobroker.esphome`, und starte die Instanz.
<!-- quelle: code=package.json:29-31@v2.0.0-beta.2; forum=755861; forum=589822; issue=#177 -->

Ein Dashboard, das nicht startet, macht die Instanz nicht rot. Dann stehen der Fehler im Log und der Grund im Reiter „ESPHome-Dashboard“.
<!-- quelle: code=src/lib/dashboard.ts:586-591@v2.0.0-beta.2; code=src/lib/dashboard.ts:686-700@v2.0.0-beta.2; code=admin/jsonTab.json5:37-66@v2.0.0-beta.2 -->
