## Welche Datenpunkte hat eine RGB/RGBW-Lampe und welche Werte erwartet sie?

<!-- abschnitt: prio=A; gewicht=15; readme=partial; cluster=entities-scripts-05,entities-scripts-06; features=entity-light,light-color-hex -->
<!-- muss beantworten: Helligkeit und Farben 0 bis 255, Hex-Farbe, Farbtemperatur, welche Werte der Lichtbefehl enthält. -->

Eine Lampe hat unter `esphome.0.<Gerät>.Light.<Schlüssel>` je einen Datenpunkt für Ein/Aus, Helligkeit, Farbkanäle, Farbtemperatur, Effekt und Hex-Farbe. Helligkeit und Farbkanäle schreibst du als Zahl von 0 bis 255, die Hex-Farbe als `#rrggbb`.
<!-- quelle: code=src/main.ts:1058-1070@v2.0.0-beta.2; code=src/main.ts:1160-1176@v2.0.0-beta.2; code=src/main.ts:1857-1872@v2.0.0-beta.2 -->

### Die Datenpunkte

Es gibt nur die Werte, die die Lampe meldet. Eine reine Ein/Aus-Lampe hat deshalb weniger Datenpunkte als eine RGBW-Lampe.
<!-- quelle: code=src/main.ts:994-1150@v2.0.0-beta.2 -->

| Datenpunkt | Werte | Bedeutung |
|---|---|---|
| `state` | `true` / `false` | an oder aus |
| `brightness` | 0 bis 255 | Gesamthelligkeit |
| `red`, `green`, `blue` | je 0 bis 255 | Farbkanäle |
| `white` | 0 bis 255 | Weißkanal, nur bei RGBW |
| `colorBrightness` | 0 bis 255 | Helligkeit des Farbanteils |
| `coldWhite`, `warmWhite` | je 0 bis 255 | Kalt- und Warmweiß |
| `colorHEX` | z. B. `#ff6600` oder `#f60` | Farbe als Hex-Wert, nur bei Lampen mit Rot, Grün und Blau |
| `colorTemperature` | Zahl | Farbtemperatur in derselben 0-bis-255-Skala wie die Helligkeit, nicht in Kelvin oder Mired |
| `colorMode` | Zahl | Farbmodus von ESPHome, z. B. `35` für RGB |
| `effect` | Text | Name des Lichteffekts aus der YAML |
| `transitionLength` | Millisekunden | Übergangsdauer, geht mit jedem Befehl mit |
| `config.rgbAutoWhite` | `true` / `false` | nur bei RGBW: `#ffffff` schaltet auf den Weißkanal |
<!-- quelle: code=src/main.ts:1058-1145@v2.0.0-beta.2; code=src/main.ts:1160-1176@v2.0.0-beta.2; code=src/main.ts:1704-1718@v2.0.0-beta.2; code=src/main.ts:1930-1944@v2.0.0-beta.2; interview=18 -->

Ein ungültiger Hex-Wert wird ohne Meldung verworfen, die Lampe bleibt dann wie sie ist.
<!-- quelle: code=src/main.ts:1878-1883@v2.0.0-beta.2 -->

### So schaltest du eine Lampe

1. Öffne im Admin den Tab „Objekte“ und dort `esphome.0.<Gerät>.Light.<Schlüssel>`.
2. Schreib einen Datenpunkt, z. B. `brightness` auf `128` oder `colorHEX` auf `#ff6600`.
3. Der Adapter schickt einen vollständigen Lichtbefehl. Meldet die Lampe ihren neuen Zustand, steht der Wert bestätigt (`ack = true`) im Datenpunkt.
<!-- quelle: code=src/main.ts:1857-1983@v2.0.0-beta.2 -->

```javascript
setState('esphome.0.<Gerät>.Light.<Schlüssel>.state', true);
setState('esphome.0.<Gerät>.Light.<Schlüssel>.colorHEX', '#ff6600');
```
<!-- quelle: code=src/main.ts:1878-1886@v2.0.0-beta.2 -->

Der Befehl enthält immer Ein/Aus, Übergangsdauer und die zuletzt bekannten Werte, aber nur die, die die Lampe laut ihren Farbmodi kann. Einen Effekt schickt der Adapter nur, wenn `effect` nicht leer ist.
<!-- quelle: code=src/main.ts:1902-1978@v2.0.0-beta.2 -->
